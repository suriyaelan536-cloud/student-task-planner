# Study Bloom — Student Task Planner

A responsive task planner built with HTML, CSS, and JavaScript. It helps students organize assignments, subjects, due dates, and priorities.

## Features
- Add tasks and assignments
- Choose a subject, due date, and priority
- Mark tasks as completed
- Filter tasks by all, to-do, or completed
- See total, pending, and completed task counts
- Save tasks in browser local storage
- Responsive layout for laptop and mobile screens

## How to run
1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Add a task and use the checkbox to mark it complete.

No installation or API key is required.

## Privacy note
Tasks are saved in local storage in the browser on the device where they are created. They are not synced to an account. Clearing browser data may remove them. Avoid entering sensitive personal information.
